1. Go to platform.claude.com (the Claude Console) and sign up or log in. This is separate from a Claude.ai chat subscription, which doesn't include API use.
  2. Buy credit: open Settings → Billing, add a payment card and click Buy credits. A few dollars is plenty to start; for this app it usually lasts months. Leave auto-reload off if you want a hard cap.
  3. Open Settings → API keys and click Create key. Name it Accounting Cloud, keep the other options as they are, and create it.
  4. Copy the key. It starts with sk-ant- and is shown only once, so paste it into step 3 below right away.
  5. Optional: on the Billing page, Spend limits → Set limit caps what you can spend in a month.

Privacy: Anthropic doesn't train its models on data sent through the API (unless you choose to share it) and deletes it from its systems within 30 days. Details.
