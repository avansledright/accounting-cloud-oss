For people comfortable installing software. Ollama runs AI models on your own computer, so nothing leaves your network and there is no bill. It needs a reasonably powerful computer: at least 16 GB of memory, and a graphics card or an Apple Silicon Mac makes it much faster.

  1. Download Ollama from ollama.com/download and install it. It runs in the background (on Windows and Mac you'll see its icon near the clock).
  2. Open a terminal (the same way as in the installation steps) and download the two models this app uses by default:
    ollama pull granite4.2:3b
    ollama pull gemma4:e4b
    Each is a few GB. Any other model works too; type its name in step 3.
  3. Let the app reach Ollama. The app runs inside Docker, so Ollama has to accept connections from it:
    • Windows and Mac: open Ollama's settings and turn on Expose Ollama to the network, then restart Ollama.
    • Linux: run sudo systemctl edit ollama, add the two lines [Service] and Environment="OLLAMA_HOST=0.0.0.0", save, then run sudo systemctl restart ollama.
    Only do this on a home network you trust: anyone on it can then use your Ollama.
  4. Enter the address in step 3 below. No API key is needed.
