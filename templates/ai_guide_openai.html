1. Go to platform.openai.com and sign up or log in. This is separate from a ChatGPT Plus subscription, which doesn't include API use.
  2. Add credit: open Settings → Billing, add a payment card and buy credit. The minimum is $5, which lasts a long time here. Turn off auto-recharge when it asks (it's on by default) if you want a hard cap. Without credit the key won't work.
  3. Open API keys and click Create new secret key. Name it Accounting Cloud, keep the default project and permissions, and click Create secret key.
  4. Click Copy. The key starts with sk- and is shown only once, so paste it into step 3 below right away.
  5. Optional: Settings → Limits → Edit spend limit, set a monthly amount and turn on Enforce a hard limit.

Privacy: OpenAI doesn't train on data sent through the API unless you opt in. It keeps requests for up to 30 days to check for abuse. This app uses the kind of request that OpenAI doesn't store for later. Details.
